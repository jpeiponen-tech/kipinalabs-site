Is Sourced 608 the official EPA 608 test?

No. It's an independent study aid, not endorsed by the EPA. An EPA-approved certifying program gives the real test.

What's free in Sourced 608?

A Core drill set and the Core mock exam. Full Access is $14.99 once, with no subscription.

What if a Sourced 608 answer looks wrong?

Email us the question. We check it against the passage it quotes and fix it in an update.

Which 608 certificate should I study for?
